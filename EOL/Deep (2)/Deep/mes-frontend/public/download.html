Install kaise kare

  1. Apne device ke hisaab se button dabao — phone/tablet ke liye upar wala (blue), plant panel (65") ke liye LAN wala (green).
  2. Download notification ya Files me APK par tap karo.
  3. Android "Unknown sources / Install unknown apps" maange to us app (Chrome/Files) ko Allow karo.
  4. Install dabao → TBDI MES icon app drawer me aa jayega.
